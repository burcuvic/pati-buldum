# Pati Buldum 🐾

Web + PWA + Capacitor Android başlangıç projesi.

## Web
`npm install && npm run build`. Vercel'de Vite projesi olarak `dist` klasörünü yayınlayın.

## Mobil
`npx cap add android && npm run android:sync` ardından Android Studio'da açın.

## Sınırlar
Bu sürümde ilanlar yalnızca cihazda tutulur; ortak veritabanı ve gerçek fotoğraf AI eşleştirme henüz yoktur. Harita Leaflet/OpenStreetMap kullanır.
